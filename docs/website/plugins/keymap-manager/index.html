Keymap Manager

A JetBrains IDE plugin by KQ42

Stop losing shortcuts to macOS.

Every JetBrains IDE ships shortcuts that macOS quietly claims for itself — Spotlight, Mission Control, window snapping, screenshots. Keymap Manager finds every one of them on any keymap you have installed, explains what is happening, and lets you fix it without leaving the IDE.

Get it on JetBrains Marketplace Source on GitHub

What it does

  • Find conflictsEvery shortcut that clashes with a macOS system shortcut, read live from the JetBrains Runtime — plus keys bound to several actions, and the overlaps the IDE itself doesn't flag. Each one is explained, with advice.
  • Fix them in placeRebind, remove, or revert to the parent keymap — one action, several, or a whole category. The rebind field takes any key you press, German keys like Ö included, and can suggest a free shortcut.
  • See what changedWhat a keymap declares itself versus what it inherits, with a filter by action name.
  • Manage keymapsActivate, duplicate, rename, delete — and import or export them as XML.

For German MacBook Pro keyboards

On a German (T1) layout, dozens of stock shortcuts can't be pressed at all: keys like / = ; [ ] sit behind ⇧ or ⌥, and there is no numpad or Insert key. The bundled MacBook Pro DE keymap is the standard macOS keymap, changed only where the layout or macOS gets in the way. Select it under Settings → Keymap.

Details

Works with
IntelliJ IDEA, PyCharm, GoLand, WebStorm, Android Studio and other IntelliJ-based IDEs, 2026.1 or newer, on macOS
Open it
Tools → Keymap Manager…, or ⌘⇧A and type “Keymap Manager”
License
Free and open source, MIT
Privacy
Collects and sends no data. It reads your installed keymaps and the macOS shortcut list locally; it never connects to the network.
Problems, ideas
GitHub issues. The plugin's help (? in its window) ends with an About block listing what a bug report needs.
